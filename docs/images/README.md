# 项目截图

把截图放在本目录，供根目录 `README.md` 引用。

## 推荐文件名（三张）

| 文件 | 建议内容 |
|------|----------|
| `01-album-home.png` | 碎纸相簿首页：三栏分册网格 |
| `02-album-cards.png` | 点开某一册后的邮件卡片墙 |
| `03-detail-sidebar.png` | 右侧邮件详情侧边栏 |

也支持 `.jpg` / `.webp`，若用其它格式请同步改 README 里的扩展名。

## 添加方式

1. 将三张图复制到本目录，按上表命名（或保持你自己的名字，并改 README 路径）
2. 在 GitHub 上 README 会自动显示相对路径图片

```bash
# 示例：从桌面拖进项目后
cp ~/Desktop/截图1.png docs/images/01-album-home.png
cp ~/Desktop/截图2.png docs/images/02-album-cards.png
cp ~/Desktop/截图3.png docs/images/03-detail-sidebar.png
```
